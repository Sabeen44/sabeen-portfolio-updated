# Sabeen — Developer Portfolio

A clean, editorial‑inspired portfolio built with **Next.js**, **React**, and **Tailwind CSS**.  
Designed to showcase projects, skills, and experience through intentional typography, subtle motion, and a minimal visual system.

## ✦ Tech Stack
- Next.js 14 (App Router)
- React
- Tailwind CSS
- Framer Motion
- Vercel (deployment)

## ✦ Features
- Responsive, fluid typography system  
- Editorial hero section with custom decorative elements  
- Project showcase with clean hover interactions  
- Accessible, semantic components  
- Optimized images via `next/image`  
- Fast, edge‑optimized deployment on Vercel  

## ✦ Project Structure
app/
components/      → Reusable UI components
projects/        → Project pages + metadata
styles/          → Global styles + tokens
layout.js        → Root layout
page.js          → Homepage
public/
images/          → Portfolio images
